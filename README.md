# ChatGPT_bias

This repo have the code for paper: "Probing Social Bias in Labor Market Text Generation
by ChatGPT: A Masked Language Model Approach" that is accepted to Neurips 2024


The file contents two jupyter notebooks,
1. The MaskedPred-StoreValue is for loading MLM and store the ouput probablities.
2. The job_analysis code is to conduct our rank based algorithm and to perform real job post analysis.

The job posting data can be downloaded from: https://www.kaggle.com/datasets/arshkon/linkedin-job-postings?resource=download
